# Domain docs

Where this project keeps its words and its decisions, and how every skill reads them.

## Before exploring, read these

- **`GLOSSARY.md`** at the root: the project's words, each defined once. None yet.
- **`docs/adr/`**: one short file per hard-to-reverse decision. None yet.
- **`docs/grills/` in the private checkout** (`jparker2006/ClosedWiz`): one file per grill. This project's grill is `docs/grills/2026-11-20-todo-app.md`. Never copy it into this public checkout.

If the glossary or ADRs do not exist yet, carry on without them.

## Private storage

The repository routing is in `issue-tracker.md`. Grills use `docs/grills/` in `jparker2006/ClosedWiz`. The handoff page is `private/orchestration/HANDOFF.md` and orchestrator state stays under `private/orchestration/`, both in that private checkout. A public source names a decision and a private-comment pointer, never exact replies or thread ids.

## Use the glossary's words

When your output names something the glossary defines, use the glossary's word.
