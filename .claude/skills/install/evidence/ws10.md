## SK-E: guards

The guards are visible in install's `## Guards` and setup's **Guards**
paragraph: install permission is not work approval; each effect waits for a
yes to its exact preview; credentials stay out of the conversation; uncertain
effects are read back, not retried; exact words are kept only as private
records; the reviewer comes from the other model family. The 33 earlier
first-fleet cases pass unchanged. No test was deleted or replaced.
